Convert QIAcuity data to DDES

DIGPCR - Ghent University

2026-11-05

Purpose

This tutorial converts QIAcuity digital polymerase chain reaction (dPCR) data to the DDES format.

Three QIAcuity file inputs are required:

  1. The analysis results as a csv file.
  2. The plate layout as a csv file.
  3. Relative fluorescence unit (RFU) files bundled in a zip file.

Load the package and example files

library(DDES)

exampleDirectory <- system.file(
  "extdata",
  "qiacuity",
  package = "DDES"
)

analysisFile <- file.path(exampleDirectory, "current-results.csv")
plateLayoutFile <- file.path(exampleDirectory, "plate-layout.csv")
rfuArchive <- file.path(exampleDirectory, "rfu-export.zip")

The example data contains two reactions, and three color-readouts.

Convert the files

Choose an output directory and call convertQiacuity().

outputDirectory <- file.path(
  tempdir(),
  "DDES-QIAcuity-tutorial"
)

conversion <- convertQiacuity(
  analysisFile = analysisFile,
  plateLayoutFile = plateLayoutFile,
  rfuArchive = rfuArchive,
  outputDirectory = outputDirectory,
  experimentId = "tutorialExperiment",
  instrument = "QIAcuity Four",
  instrumentSoftwareVersion = "QIAcuity Software Suite 2.5.0",
  dateTime = "202506301127"
)
#> Reading QIAcuity files
#> Creating the DDES main file
#> Creating the DDES assay file
#> Creating the DDES intensity files
#> Writing the DDES files

This writes a main file, an assay file, one intensity file per reaction, and a .ddes archive bundling all files.

basename(conversion$files)
#> [1] "DDES_tutorialExperiment_5160815c-092d-49ea-946c-cf7bcb49432a_202506301127_main.tsv"        
#> [2] "DDES_tutorialExperiment_5160815c-092d-49ea-946c-cf7bcb49432a_202506301127_assays.tsv"      
#> [3] "DDES_tutorialExperiment_5160815c-092d-49ea-946c-cf7bcb49432a_202506301127_intensity_A1.tsv"
#> [4] "DDES_tutorialExperiment_5160815c-092d-49ea-946c-cf7bcb49432a_202506301127_intensity_A2.tsv"
basename(conversion$archive)
#> [1] "DDES_tutorialExperiment_5160815c-092d-49ea-946c-cf7bcb49432a_202506301127.ddes"

Using your own QIAcuity data

You can simply replace the three example paths above, with paths to your own files.
